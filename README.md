# Hugr

A project memory and intelligence system for agents.

Designed to run locally, in the cloud, or as a hybrid service near your code.

Storage starts with libSQL/Turso Vector so memory, search, graph edges, and embeddings can live in one SQLite-compatible database.

See [docs/DEV_PLAN.md](docs/DEV_PLAN.md) for the current open development plan.

Inspired by Cognee, TraceDecay, Serena, Graphiti, Mem0, LangMem, FastContext, ast-grep, and FFF.
